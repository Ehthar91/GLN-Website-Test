GLN Bus Call — 1-Hour Auto-Expire Update

Replace these files in the ROOT of your GitHub repository:
  1. bus-call.js
  2. index.html

Behavior:
- If the caller browser disconnects/closes, the live Bus Call session expires after 1 hour.
- The room code remains reserved for the caller under the existing reservation system.
- Teachers are prevented from seeing stale calls after the session expires.
- Recent Call history entries automatically disappear after 1 hour.
- Reopening an expired session starts with clean calls/history.
- No Firebase rules change is required for this update.
