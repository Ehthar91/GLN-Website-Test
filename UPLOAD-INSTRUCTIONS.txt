GLN BUS CALL — ADD-ON BUSES UPDATE

Quick update:
1. Open your GitHub repository.
2. Upload/replace these three files in the repository root:
   - bus-call.js
   - bus-call.css
   - index.html
3. Commit the changes.
4. Wait for GitHub Pages to deploy, then hard-refresh the site.

New behavior:
- Regular Bus Call remains unchanged.
- Caller can open “Add-On Buses”.
- Add-On defaults to First Call + Second Call selected together.
- First, Second, and Last Call are multi-select, so any combination can be sent as one alert.
- Classroom popups and Recent Calls identify these as ADD-ON BUS calls.
