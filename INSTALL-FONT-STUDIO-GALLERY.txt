GLN Karen Font Studio — 90 Saw Cfcr Legacy Style Gallery
=======================================================
This is the FIRST STAGE of the legacy-font adaptation project.
It adds a visual, searchable font-style gallery to the standalone
Type Studio (/type/). It DOES NOT convert these fonts to Unicode.

GITHUB INSTALLATION — PATCH ONLY
  Replace: type/index.html (inside your existing type folder)
  Replace: type-page.css (repository root)
  Add: type-font-studio.js (repository root)
  Add: assets/saw-cfcr-previews.png
  Add: assets/saw-cfcr-styles.json (optional style metadata)

Keep folder paths. If assets/ does not exist, create it on GitHub
via the Add file > Create new file method or upload by dragging
files into the assets folder.
Do not replace the ROOT index.html with type/index.html.

FEATURES
  • All 90 original styles represented by previews created from
    the user-supplied legacy TTF collection.
  • Search by style name/number; show more; star favorites.
  • Click a card to see an enlarged visual sample.
  • No TTF files are shipped in this ZIP.
  • Existing Unicode typing, Sgaw/Pwo/English keyboard, drafts,
    copy, Download TXT, creator badge, and themes stay unchanged.

LIMITATIONS
  • Gallery samples show the legacy keyed text, NOT Unicode text.
  • Selecting a Saw Cfcr style does not change the text editor font.
  • Future work: mapping and Myanmar shaping for all 90 styles,
    review of copyright/reuse permission, and Unicode QA.
  • No license was found in the supplied legacy font ZIP. Confirm
    your rights to publish font-derived previews before making
    the gallery public. Original TTF binaries are NOT included.
